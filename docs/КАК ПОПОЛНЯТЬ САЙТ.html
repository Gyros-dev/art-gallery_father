Как сохранить в PDF: нажмите Cmd+P (на Windows Ctrl+P), в списке принтеров выберите «Сохранить как PDF» и нажмите «Сохранить». Поля, разрывы страниц и размер A4 уже настроены. Эта рамка на печать не попадёт.

Сайт наполняется через панель управления — обычные формы, без файлов и кода. Это основной и рекомендуемый способ. Ручная загрузка файлов описана в конце как запасной путь.

С телефона и планшета

Панель полностью работает и с телефона — открывается в обычном браузере по тому же адресу app.pagescms.org, ставить ничего не нужно.

  • Список разделов прячется за кнопкой ☰ в левом верхнем углу.
  • Картинки загружаются прямо из галереи телефона или камеры.
  • Перетаскивать картинки (чтобы поменять их порядок) нужно так: нажать на картинку и, не отпуская палец, вести её на новое место.
  • Если страница не прокручивается, потому что палец попал на картинку — начните движение с пустого места рядом.
Поломка не попадёт на сайт. Сборка проверяет данные. Если что-то не так, публикации не будет — останется прежняя рабочая версия, а на почту придёт письмо от GitHub с описанием проблемы.

Про картинки

Грузите самый большой и качественный файл, какой есть — jpg, png или webp. Сайт сам сделает из него три размера:

  • маленький эскиз для сетки,
  • средний для страницы галереи,
  • оригинал во всю величину — он открывается, когда работу разворачивают на весь экран.

Ужимать и подгонять ничего не надо, размер на сайте подстраивается сам.

Про материалы

Список уже заполнен теми материалами, что есть на сайте: медь, горячая эмаль, стекло, серебро, золото, дерево, латунь, смешанная техника. Отмечайте нужные галочками — они встанут в описание через запятую.

Нужного материала нет в списке? Впишите его в соседнее поле «Другие материалы» обычным текстом, через запятую: сталь, эмалевая крошка. Он добавится в подпись после тех, что отмечены галочками.

2. Изменить, заменить или удалить

Изменить работу

«Работы — <категория>» → щёлкнуть по работе в списке → поправить → Save. Название можно менять в любой момент, картинка при этом не потеряется.

Заменить или добавить картинку

В карточке, в поле «Изображения»: навести на ненужную картинку → крестик, затем загрузить новую. Порядок картинок меняется перетаскиванием мышкой.

Поменять местами части серии

Просто перетащите картинки внутри поля «Изображения». Как расставите — так и будет на сайте.

Удалить работу с сайта

Это два шага, и второй обязателен:

  1. Открыть карточку работы → меню с тремя точками вверху справа → Delete.
  2. Зайти в Media → «Картинки — <категория>» и удалить там саму картинку.

Если сделать только первый шаг, работа вернётся на сайт — но уже без описания, с названием по имени файла. Так задумано: картинка в папке всегда попадает в галерею, даже если карточку кто-то случайно удалил.

Случайно ничего не удалится

Панель переспрашивает перед каждым удалением:

Что удаляетеЧто спросит
Работу, статью«Are you sure you want to delete this file?» и покажет, какой именно файл
Картинку в MediaТо же окно с названием файла
Строку в списке (соцсеть, избранное)«Remove this item?»

Чтобы удаление произошло, нужно нажать красную кнопку Delete во всплывшем окне. Кнопка Cancel отменяет.

Единственное действие без вопроса — корзинка на картинке внутри карточки. Но она ничего не удаляет по-настоящему: картинка лишь отцепляется от карточки, файл остаётся на месте. И пока вы не нажали Save, ничего не изменилось — уйдите со страницы без сохранения, и всё вернётся как было.

Если всё-таки удалили лишнее

Ничего не пропадает навсегда. Каждое изменение сохраняется отдельной записью в истории, и любой файл можно достать обратно:

  1. Откройте github.com/Gyros-dev/art-gallery_father
  2. Нажмите на строку с часами и числом коммитов — это история изменений.
  3. Найдите запись об удалении, откройте соседнюю запись выше неё (то есть состояние до удаления) и нажмите Browse files.
  4. Найдите нужный файл, откройте его и скачайте кнопкой Download raw file.
  5. Загрузите обратно через панель.

Если запутаетесь — напишите мне, восстановление занимает пару минут.

Удалить выставку или статью

Открыть → меню с тремя точками → Delete. Здесь одного шага достаточно.

3. Серия работ (диптих, триптих, несколько связанных)

Серия — это одна карточка с несколькими картинками.

  1. Создайте карточку как обычно.
  2. В поле «Изображения» загрузите все части.
  3. Порядок — перетаскиванием прямо в списке. Как расставите, так и будет на сайте.
  4. Расположение частей — выпадающий список:
ВыборЧто получится
АвтоматическиСайт решит сам: до трёх частей и вытянутые вверх — в ряд, остальные — квадратом
В ряд ▭ ▭ ▭Все части в одну линию
Квадратом ▭ ▭ / ▭ ▭Части сеткой 2×2, 3×3…

Размеры у частей разные? Перечислите через запятую в поле «Размер»: 30х40 см, 25х25 см, 30х30 см.

Подписи частей («Хлеб», «Рыба») берутся из имён файлов. Хотите подписи — назовите файлы 1. Хлеб.jpg, 2. Рыба.jpg перед загрузкой. Не хотите — покажется просто «1/4», «2/4».

4. Порядок работ в категории

По умолчанию работы идут по алфавиту. Это менять не обязательно.

Хотите вынести работу вперёд — впишите «Номер в категории»: 1, 2, 3. Работы с номерами встают в начало по возрастанию, все остальные — за ними, как обычно. У работ без номера ничего не меняется.

6. Настройки сайта

Раздел «Настройки сайта» — название, описание для поисковиков, адрес, город, контакты и «Избранное».

  • Фотография художника — снимок на странице «Художник». Нажать на поле → Upload → выбрать файл (можно перетащить мышкой). Подойдёт фотография любого размера и формата: сайт сам впишет её в рамку, вёрстка не поедет. Лучше всего смотрится вертикальный или квадратный снимок; широкий будет аккуратно подрезан по бокам.
  • Почта и телефон. Пусто = контакт просто не показывается на сайте.
  • Соцсети. Пустая ссылка = кнопки нет.
  • «Избранное на главной» — названия работ в нужном порядке; они крутятся в карусели на главной. Первая работа из списка становится картинкой-превью, которую видят люди, когда вы отправляете ссылку на сайт в мессенджере. Оставите пустым — покажутся 6 случайных.

7. Публикации

Раздел «Публикации и статьи» → «+». Первая строка текста = заголовок, дальше сам текст. Появится в «Литературе».

PDF-пособие кладётся в папку docs/, и на него добавляется строка на странице pages/literature.html — это уже ручная правка.

Запасной способ: файлы напрямую

Панель управления — просто удобная обёртка над файлами репозитория. Всё то же самое можно сделать руками, и старый порядок продолжает работать.

  • Через сайт GitHub: открыть нужную папку на github.com → «Add file» → «Upload files» → перетащить → «Commit changes».
  • С компьютера: положить файлы в папки проекта и выполнить git add -A && git commit -m "новые работы" && git push.

Как это устроено:

ЧтоГде лежит
Картинки работimages/art/Горячая эмаль, Арт-объект
Карточка работы (название, материалы, размер, год, порядок)content/works/enamel/<Название>.md, content/works/object/…
Выставкиdata/exhibitions.json
Фото с выставокimages/exhibitions/<имя папки из карточки выставки>
Статьиcontent/texts
Название сайта, домен, контакты, «Избранное»data/site.json

Картинка без карточки тоже попадёт на сайт — название возьмётся из имени файла, а подпапка внутри категории станет серией. Карточка нужна, чтобы задать материалы, размер, год, порядок частей и раскладку.

Новая категория — новая папка в images/art, например images/art/Живопись. На сайте появится новый фильтр. Чтобы категория появилась и в панели управления, нужно добавить её в файл .pages.yml — это правка на десять строк, по образцу соседних категорий.
